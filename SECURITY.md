# Security policy

This policy covers the Python packages in this repository: `rakomi`, `rakomi-sdk`, `rakomi-cli` and
`rakomi-mcp`, their source and their releases on PyPI.

## Reporting a vulnerability

Please do not open a public issue for a security report. Email **security@rakomi.com**.

Rakomi's security contact details, including the encryption key for reports and the preferred
languages, are published at <https://rakomi.com/.well-known/security.txt>. The Rakomi security
policy is at <https://rakomi.com/security>.

## Supported versions

These packages are on the `0.x` line. Per Semantic Versioning 2.0.0 §4, major version zero is for
initial development and the public API should not be considered stable. Fixes are released in the
latest `0.x` version; there is no separate support window for earlier versions.

## Published versions

PyPI does not allow a deleted release to be uploaded again under the same version number. A defect in
a published version is corrected by publishing a fixed, higher version.
